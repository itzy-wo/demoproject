# Mini E-Commerce Demo Project

## Description
A modern, clean, and fully responsive mini e-commerce web application where customers can browse products, add items to their cart, and place orders using Cash on Delivery. It includes an admin panel for managing categories, products, and tracking customer orders.

## Technology Stack (MERN)
- **Frontend:** React.js, Vite, JavaScript, Tailwind CSS, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT (JSON Web Tokens), bcrypt

## Project Scope
This project focuses on providing a clean, small-scale demonstration of a functional e-commerce flow.

**Included Features:**
- Customer and Admin Authentication
- Admin panel to manage Categories, Products, and Orders
- Public website to browse and search/filter products
- Shopping Cart with stock validation
- Checkout with Cash on Delivery (COD)
- Customer order history

**Explicitly Excluded Features:**
- Payment gateway integration
- Wishlist
- Reviews
- Coupons
- Suppliers / Multi-vendor features
- Advanced analytics

## Current Project Status
**Implementation has NOT started yet.** The project is currently in the documentation and planning stage. No application source code (client or server) has been created.
